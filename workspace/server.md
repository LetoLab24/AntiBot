# Сервер — заполнить один раз

Паролей и ключей сюда не писать.

- **Сайт:** shop.example
- **Как зайти:** `ssh shop` — запись `Host shop` в `~/.ssh/config` на этом компьютере, вход по ключу.
- **Команда сторожа:** `sudo antibot` (учётке агента разрешена только она — так ставит `install.sh --agent-user`).
- **Настройки:** `/etc/antibot/antibot.ini`; база — `/var/lib/antibot/`; журнал сторожа — `/var/log/antibot.log`.
- **Режим сейчас:** observe (с ДД.ММ.ГГГГ).
