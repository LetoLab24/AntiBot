# Что нового

Обновиться: `git pull && sudo ./install.sh`. Настройки (`/etc/antibot/antibot.ini`) и база не меняются.

## 0.1.0 — 28.10.2026

Первая версия, идёт пилот.

- **Сторож:**
  - закрывает сканеров уязвимостей сам, в том числе за SQL-инъекции в поиске;
  - находит парсеров каталога, безголовые браузеры, глубокую пагинацию, `HEAD` по страницам, подбор пароля, слишком частых, поддельных поисковиков и ИИ-ботов;
  - по умолчанию работает в режиме наблюдения.
- **Сводки для разбора:** `--daily` (за сутки, с кандидатами в бан и доводами), `--who` (что делал адрес), `--block-ua` (бан по точному имени браузера с проверкой, нет ли под ним людей).
- **Наборы шаблонов:** свой движок, Next.js, 1С-Битрикс, OpenCart, WooCommerce.
- **Рабочая папка `workspace/`** для ежедневного разбора с Claude Code, Codex или ChatGPT.
- **Проверка:** прогон по журналам большого сайта за 12 дней (~5 млн запросов). Сканеры и подделки под поисковики совпали с проверенным сторожем этого сайта адрес в адрес.
